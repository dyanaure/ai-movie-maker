# AI Movie Maker

A script-to-movie pipeline for generating cinematic AI films scene by scene.

## Goal

Paste a screenplay, split it into production-ready scenes and shots, preserve character descriptions across shots, generate video/audio assets, and assemble the result into a final MP4.

## Planned pipeline

1. Screenplay -> structured scenes
2. Character bible and continuity data
3. Shot prompts and camera directions
4. LTX-2 / ComfyUI video generation
5. Dialogue, ambience, music and SFX
6. Subtitle generation
7. FFmpeg assembly
8. Export in 16:9 or 9:16
